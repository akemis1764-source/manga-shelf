Google Drive 初期設定
Google Driveで同期するには、Google CloudでAPIキーを取得する必要があります（無料・一度だけ）。
1
Google Cloud Console を開き、新しいプロジェクトを作成（名前は「本棚」などでOK）
2
左メニュー「APIとサービス」→「ライブラリ」で Google Drive API を検索して「有効にする」
3
「APIとサービス」→「OAuth同意画面」→ 外部を選択 → アプリ名に「本棚」→ 自分のメールを入力 → テストユーザーに自分のGmailを追加 → 保存
4
「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
アプリケーションの種類: ウェブ アプリケーション

ローカルファイルとして開く場合は null を追加
→ 作成 → 表示される クライアントID をコピー
